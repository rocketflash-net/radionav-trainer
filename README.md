# RadioNav Trainer

Simulator web sederhana untuk latihan intercept dan approach dengan navigasi radio:

- **VOR Radial** — intercept radial inbound/outbound dengan HSI (CRS/OBS, CDI, TO/FROM)
- **NDB / ADF** — intercept QDM/QDR hanya dengan RMI
- **ILS Approach** — intercept localizer dan glideslope, dinilai di DA 200 ft

Buka `index.html` langsung di browser, tidak perlu build.

Kontrol keyboard: ←/→ heading bug, Q/E course, ↑/↓ vertical speed (ILS), Spasi jeda, N skenario baru, H petunjuk.

> Untuk memahami konsep, bukan pengganti latihan dengan instruktur atau simulator tersertifikasi.
